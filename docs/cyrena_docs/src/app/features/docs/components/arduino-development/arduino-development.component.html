Sketch Structure

Arduino IDE sketches follow a simple flat-file layout. Cyréna understands this structure and will not attempt to reorganize it.

File / Folder Purpose
*.ino The main sketch file containing setup() and loop() functions.
*.h / *.cpp Optional header and source files for custom libraries or helper code.

Cyrena respects the flat sketch structure: the AI will not restructure your Arduino project into folders or introduce files that break the IDE's expected layout. All generated code stays within the single .ino file or its adjacent helper files.
