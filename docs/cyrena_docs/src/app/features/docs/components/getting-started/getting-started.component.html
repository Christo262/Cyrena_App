Configuring Connections

Ollama

Run AI models entirely on your own machine. No internet required. No data leaves your device.

  1. In Settings, select the Ollama tab
  2. Click the plus icon to add a connection
  3. Fill in the host URL (usually http://localhost:11434)
  4. Select your model from the dropdown
  5. Adjust parameters if needed — then save

OpenAI

Use OpenAI's cloud models. Requires an API key and internet connection.

  1. In Settings, select the OpenAI tab
  2. Click the plus icon to add a connection
  3. Paste your OpenAI API Key
  4. Enter the model ID (e.g. gpt-5)
  5. Save the connection

Tips

  • You can have multiple Ollama and OpenAI connections configured at the same time
  • Switch between models mid-chat — Cyréna remembers the conversation context
  • Set a Default Connection in the Defaults tab so new chats start with your preferred model
  • Ollama parameters let you fine-tune generation behavior: temperature for creativity, num_context for memory window, min_p for sampling diversity
