UI Overview

A quick tour of the Cyréna interface and what you'll see as you work.

Launch Window

This is the first screen you see when you open Cyréna — your home base for starting conversations and managing projects.

1
Navigate to Launch Window

Your starting point — access all projects and conversations from here.

2
Settings

Configure connections, preferences, and platform options.

3
Conversations / Chats

Browse and continue existing chat sessions.

4
Working Projects

Projects are categorised so you can quickly find what you're working on.

5
New Chat Text Area

Creates a new general-purpose chat — not tied to any development project.

6
Create Coding Chats

Start a development-focused chat tied to a specific project or solution.

7
Install & Manage Extensions

Add new capabilities to Cyréna by installing or configuring extensions.

Development Window

When you open a coding chat, the interface adapts to your project type with tools tailored for that workflow.

1
Project Context Switching

Switch between environments or projects. Applicable to .NET Solutions and PlatformIO when multiple environments are configured.

2
File History

Tracks changes per file per iteration. Review what changed, revert to a previous version, or keep the current one.

3
File Attachment

Attach files to the conversation for the AI to reference or modify.

4
API References

Review API References the AI generated for your project. Edit, export, import, or delete them as needed.

5
Chat Export

Save your entire conversation to a text file for sharing or archiving.

Adaptive Interface

The Development Window changes depending on the project type you are working on — tailored toward the specific tools and workflows of .NET, PlatformIO, Arduino, Angular, and more.
