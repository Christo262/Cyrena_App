About Cyréna

A personal project born from the need to find the right LLM for real development work.

The Story

Cyréna started as a simple experiment: could a large language model reliably help with day-to-day software development? The answer turned out to be "it depends — heavily on which model you choose."

Over months of testing, I have run dozens of models through real tasks — building Arduino sketches, configuring ESP-IDF projects, writing .NET applications, and maintaining complex codebases. Some models excelled. Others stumbled. A few were outright frustrating.

This site exists to share those findings so other developers can skip the trial-and-error and pick a model that actually fits their workflow.

Review Philosophy

Every review on this site comes from hands-on use inside the Cyréna desktop app. I do not benchmark token speeds or run synthetic tests. Instead, I judge models on what matters for real work:

  • Accuracy — Does the code compile? Does it follow modern conventions?
  • Reliability — Does the model consistently produce useful output, or does it flake out?
  • Tool use — Can it call functions, search the web, and interact with the environment when needed?
  • Context awareness — Does it understand the project structure, or does it blindly patch files?
  • Developer experience — Is working with the model smooth, or does it fight you every step of the way?

The Cyréna App

Cyréna is a custom desktop development-agent application built to bridge the gap between LLM chat interfaces and actual software engineering. It supports both offline models (via Ollama) and cloud providers, giving flexibility without sacrificing privacy when it is needed.

Key features include:

  • Unified interface for local and cloud LLMs
  • Project-aware context management
  • Sticky notes and API references for persistent rules
  • Function calling and web search integration
  • File-aware code generation and editing

More details about the app will be added here as the project evolves.
