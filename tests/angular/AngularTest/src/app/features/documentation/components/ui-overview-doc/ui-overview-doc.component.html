UI Overview

A visual guide to the main application windows and their features.

Launch Window

Launch Window Overview
  1. Navigate to launch window — Main entry point of the application.
  2. Settings — Configure application preferences and options.
  3. Conversations / Chats — Access your chat history and ongoing conversations.
  4. Working Projects — Browse your projects, categorised for easy navigation.
  5. New chat text area — Start a new general chat (not tied to development).
  6. Create coding chats — Initiate development-focused conversations.
  7. Install & Manage Extensions — Add or remove plugins and extensions.

Development Window (.NET Solution)

Working Window Overview
  1. Project Context switching

    Only applicable to .NET Solution & PlatformIO in case of multiple environments.

  2. File History

    Tracks changes per file per iteration. Allows review of changes, revert or keep.

  3. File Attachment — Attach files to your current session.
  4. API References

    Review API References the AI generated. Allows editing, exporting, importing and deleting.

  5. Chat Export

    Prompts to save the conversation to a text file.

Note: The Development Window changes depending on the project type you are working on, tailored toward the project / solution.
